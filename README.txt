APLIKASI PENJUALAN - VERSI 1
Untuk Android / Infinix Note 30

Isi versi ini:
- Nama toko
- Nama produk
- Qty
- Harga satuan
- Diskon %
- Hitung subtotal, potongan diskon, dan total

Catatan:
File ini adalah SOURCE PROJECT Android, bukan APK siap instal.
Untuk menghasilkan APK, buka project ini di Android Studio lalu Build > Build APK(s).
Setelah APK dibuat, kirim APK ke HP Infinix Note 30 dan instal.

Pengembangan berikutnya bisa ditambah:
- database toko
- daftar produk
- login salesman
- target penjualan
- order history
- export Excel
- cetak/share nota
- sinkronisasi cloud
